───────────────────────────────────────────────────────────────────────────
LESSONS LEARNED
───────────────────────────────────────────────────────────────────────────

1. MySQL vs PostgreSQL
   - Initial migration used PostgreSQL syntax
   - Converted to MySQL syntax (ENUM inline, JSON, TEXT)

2. Unique Constraint Length
   - MySQL 3072-byte limit for unique indexes
   - Shortened VARCHAR lengths for indexed fields

3. Decimal Precision
   - Never use JavaScript Number for money
   - Use Decimal type throughout
   - Convert to string for JSON serialization

4. Concurrent Sync Prevention
   - In-memory Map to track active syncs
   - Prevents race conditions and data corruption

5. Transaction Boundaries
   - Wrap all sync operations in transaction
   - Ensures all-or-nothing consistency
